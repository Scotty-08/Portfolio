# Maze Solver Visualizer

An interactive maze solver built with HTML, CSS, and JavaScript. Users can draw walls, move the start and finish points, generate a random maze, and watch breadth-first search find the shortest path.

## Features

- Interactive 24 by 16 grid
- Wall, start, finish, and erase tools
- Random maze generator
- Breadth-first search pathfinding
- Animated visited cells and final path
- Visited-cell and path-length counters

## How to Run

Open `index.html` in a browser.
